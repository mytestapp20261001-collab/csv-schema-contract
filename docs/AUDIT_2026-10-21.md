## Implemented corrections

1. **Decimal context isolation (10 data repositories):** a host with `decimal.getcontext().traps[InvalidOperation] = False` made the strict parser accept `[1e99999999999999999999999999]` as NaN. Explicit constructor contexts now reject it without modifying host flags. TOML still accepts its valid NaN/Infinity literals. The rounding tool additionally isolates arithmetic precision/traps/exponent bounds; numeric-key normalization consistently raises its documented input error.
2. **Cookie numeric authorities:** `https://127.1/` and `https://10.1/` with `Domain=1` incorrectly matched as DNS suffixes. The strict subset now rejects ambiguous numeric-looking hosts, retaining canonical IP identity and ordinary DNS behavior.
3. **Shebang budgets:** `--max-header-bytes 100000000000000000000` caused OverflowError/traceback even for a tiny valid script. Reads now use chunks no larger than 4096 bytes and stop at the first newline.
4. **Artifact reserved names:** `COM¹` and `LPT².txt` now fail the Windows basename policy; nonreserved neighboring spellings remain accepted.
5. **Discovery:** [50-tool metadata](tool-discovery.json), [usage guide](../DISCOVER.md) and an offline selector provide specific task summaries, requirements, exact repository identities, pinned README/skill references and synthetic smoke commands.

Each source correction includes regressions and independent read-only review. Original `MIGRATION.json` hashes remain unchanged; per-repository `MAINTENANCE_2026-10-21.json` receipts bind the verified repository ID, original/new hashes, base commit and reasons. Validators reject absent/invalid receipts, protected README changes and wrong hashes. Source fixes do not change promotional wording or guidance groups.
